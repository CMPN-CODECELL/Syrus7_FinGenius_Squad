SkillSync — integrated backend installation fix

1. Extract this ZIP to C:\SkillSync (short path avoids Windows MAX_PATH issues).
2. Open SkillSync-v25\backend and double-click install_dependencies.bat.
3. After it succeeds, run start_backend.bat.
4. Keep your own backend\.env private; create it from .env.example if needed and add your API credentials locally.

This archive preserves the complete Feature 1 project and integrates the backend installer fix. The local virtual environment and node_modules are intentionally excluded; they should be installed on the target computer.
